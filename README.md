# MarkMyWord
[![Registry](https://img.shields.io/badge/Registry-SpecWorks-blue)](https://spec-works.github.io/registry/parts/markmyword/)


Software component for bidirectional conversion between CommonMark/GitHub Flavored Markdown and Microsoft Word (.docx) documents.

## Specifications

Implements [CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/) and [Office Open XML (ECMA-376)](https://www.ecma-international.org/publications-and-standards/standards/ecma-376/).

See [specs.json](specs.json) for complete specification references.
