# MarkMyWord Example Document

This document demonstrates the various markdown features supported by MarkMyWord.

## Headings

MarkMyWord supports all six levels of headings:

### Level 3 Heading
#### Level 4 Heading
##### Level 5 Heading
###### Level 6 Heading

## Text Formatting

You can use **bold text** and *italic text* in your documents.

You can also combine them: ***bold and italic***.

## Inline Code

Use `inline code` for variable names or short code snippets like `var x = 10;`.
