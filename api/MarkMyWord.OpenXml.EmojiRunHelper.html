Helper for creating Word runs that apply the correct font for emoji characters. Splits text into emoji and non-emoji segments, applying "Segoe UI Emoji" to emoji runs so that Word renders them in full color instead of monochrome outlines.

AppendText(OpenXmlCompositeElement, string, RunProperties?)

Appends one or more runs to the parent element, splitting text into emoji and non-emoji segments. Emoji segments get the emoji font applied. Works with Paragraph, Hyperlink, or any OpenXmlCompositeElement that accepts Run children.
